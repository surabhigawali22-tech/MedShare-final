IMPORTANT NOTES FOR ANDROID APK TESTING
==========================================
- Backend/API Required: YES
  The Android APK communicates with the Express REST API backend over HTTP. The backend MUST be running on your laptop for authentication and data to work.

- How to Start Backend:
  In terminal, navigate to: Medshare-main/server
  Run: npm start
  (or: node src/server.js)

- Backend URL for Phone:
  http://192.168.1.8:5000
  (Pre-configured in native Capacitor APK build)

- Wi-Fi Requirement:
  Your phone and laptop MUST be connected to the SAME Wi-Fi network (or phone connected to laptop's mobile hotspot) so your phone can reach 192.168.1.8.

- Auto-Login & Demo Mode:
  - On first app open, the APK automatically attempts to log in as 'donor.pharma@example.com'.
  - Quick Persona Switcher: Tap the top-right profile avatar in the navigation bar to instantly switch between Admin, Verifier, Donor, and Recipient personas with one tap.
  - The login modal also pre-fills 'Password123!' by default.

- OTP / Verification Requirement:
  - OTP Required: NO (no SMS or email verification codes required).
  - All 13 demo accounts listed above are already pre-verified (verified = 1) in the database.
